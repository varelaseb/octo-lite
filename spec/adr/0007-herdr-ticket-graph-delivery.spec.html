ADR 0007: Herdr ticket-graph delivery

Specifications / octo-lite / ADR 0007

Supersedes ADR 0005. Decision behind delivery.

User stories

As an operator, I can invoke implement-spec on an accepted spec and have its ready tickets delivered in parallel onto one PR branch.

As an operator, I can read Linear to see which tickets are actually in progress and which are integrated and pushed.

Context

Post-shaping delivery had gathered role resolution, receipts, journals, exact-model gates, verdict publication, QA gates, and lifecycle transitions around ordinary implementation.

An accepted spec defines outcomes whose ticket graph, once filed, shows through its blocking relations the work that can safely run in parallel.

Decision

After spec acceptance, implement-spec owns delivery: it files the spec's dependency-linked ticket graph and fills its ready frontier (implement).

The lane owner launches temporary Herdr workers directly, each under its hand-written role contract (roles): implementers in their own worktrees, one integrator at a time onto one PR branch (integrate), and a fresh code reviewer on the integration head (review).

Linear holds the ticket graph and its live work state (truthful Linear).

Why

Independent tickets run at once, so dependencies, not a fixed phase sequence, set throughput.

Workers launched directly, passing durable pointers and commits, are simpler to run and to watch than a loop of machine receipts and verdict gates.

Alternatives rejected

OptionRejected because
Keep the post-shaping loop, with role resolution, receipts, journals, exact-model gates, and verdict publicationIts deterministic gates cost ceremony around ordinary implementation, and its state stood apart from the actual work

Consequences

Agents communicate through durable pointers and commits instead of copied briefs and machine receipts.

Delivery gives up deterministic role and verdict gates in exchange for simpler execution, direct observability, and Linear state that reflects actual work.

Required checks and the human gates still hold every merge.
