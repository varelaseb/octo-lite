Every octo-lite agent, whatever its role or none, follows these rules, which `herdr-spawn` hands it beside any operating model (herdr-transport spec `#roles-every-role`).

Link to the source, edit the source (octo-lite spec `#roles-one-source`). Every fact, rule, or decision has one source. Anything you write that needs it, such as a brief, contract, skill, spec, comment, or report, links that source at its anchor and never restates it. Make a change, or fix a wrong line, in the source, never as a correction beside a copy; a copy you meet becomes a link to its source.

Raise no permission prompt (octo-lite spec `#roles-no-prompt`). You mostly run in a pane nobody watches, where a command your CLI cannot rule out as safe stops you at a prompt nobody answers. Write or edit a file with your own file tool, such as Claude's Write and Edit. To run a script, write it with that tool to a file in your scratch folder, `$TMPDIR`, then run that file; never pass a script or a file's text to the shell through a heredoc. Remove nothing from your scratch folder, which goes when you are closed: a run that needs a clean folder makes a fresh one with `mktemp -d` in place of emptying an old one. Any other file you remove is one you made, removed by its literal path, never by a glob, a variable, or a folder's whole contents.
